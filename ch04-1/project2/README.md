# ch04-1 실습과제2

## 문제1
현재 작업 디렉터리에서 루트 디렉터리로 이동하는 절대경로를 이용하는 명령어는?

## 답
cd / 이다. <br>

## 문제2
현재 작업 디렉터리에서 루트 디렉터리로 이동하는 상대경로를 이용하는 명령어는?

## 답
cd ../../.. 이다. <br>

## 문제3
/usr/lib/gcc/x86_64-linux-gnu 디렉터리로 이동하는 절대경로를 이용하는 명령어는? <br>
디렉터리 입력시도 자동완성 기능 이용할 것

## 답
cd /usr/lib/gcc/x86_64-linux-gnu 이다. 이때 자동완성 기능을 이용하려면 각 경로의 앞글자를 입력한 후 Tab키를 누르면 된다.<br>

## 문제4
/usr/lib/gcc/x86_64-linux-gnu 디렉터리로 이동하는 상대경로를 이용하는 명령어는? <br>
디렉터리 입력시도 자동완성 기능 이용할 것

## 답
cd ../../../usr/lib/gcc/x86_64-linux-gnu 이다. 마찬가지로 이대도 Tab 키를 이용하면 자동완성 기능을 활용할 수 있다. <br>
