# ch04-1 실습과제1

## 문제1
다음 단어 또는 기호의 의미를 설명하라.<br>
* 디렉터리<br>
* 서브 디렉터리<br>
* 작업 디렉터리<br>
* 홈 디렉터리<br>
* ~<br>
* .<br>
* ..<br>
* /<br>
* 상대경로<br>
* 절대경로<br>

## 답
* 디렉터리 - 여러 개의 파일을 모아 놓은 파일 (폴더 개념)<br>
* 서브 디렉터리 - 디렉터리 안에 포함되어 있는 디렉터리<br>
* 작업 디렉터리 - 현재 위치하여 작업하는 디렉터리<br>
* 홈 디렉터리 - 사용자 별로 할당되는 개인용 디렉터리<br>
* ~ - 홈 디렉터리를 나타내는 기호<br>
* . - 현재 작업 디렉터리를 의미하는 기호<br>
* .. - 부모 디렉터리를 의미하는 기호 (현재 작업 디렉터리의 상위 디렉터리를 지정하기 위해 사용)<br>
* / - 처음 /는 루트 디렉터리를 의미하고 다음 /는 디렉터리를 구분하는 문자<br>
* 상대경로 - 현재 작업 디렉터리를 기준으로 표기하는 상대적인 경로로, / 없이 시작한다. <br>
* 절대경로 - 루트 디렉터리부터 해당 파일에 이르는 경로를 모두 표시하는 경로로, 반드시 /로 시작한다.<br>
