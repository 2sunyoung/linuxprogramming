# ch31 실습과제1

## 문제1
프로그램 개발과정 편집->선행처리->컴파일->링크->실행 단계를 자세히 설명하시오.

## 답
편집: 사용자가 소스파일을 작성하는 단계이고, 결과 파일은 소스파일이다.<br>
선행처리: 컴파일 과정 전에 선행처리 명령문들(# 기호로 시작, 세미콜론(;)이 붙지 않는다.)을 선행처리기가 다른 문장으로 단순 치환해 주는 단계이고, <br>
        결과 파일은 여전히 소스파일이다. 예를 들어 소스코드에 매크로 상수로 적혀있던 단어나 문장이 매크로 몸체로 선행처리기에 의해 단순히 치환되는 과정이 선행처리이다.<br>
컴파일: 소스파일(c언어)을 목적파일(기계어)로 번역하는 단계이고, 결과 파일은 목적파일이다.<br>
링크: 여러 개의 목적파일을 라이브러리 파일(목적파일)과 연결하여 하나의 실행 파일을 생성하는 단계이고, 결과파일은 실행파일이다.<br>
실행: 실행파일의 내용을 컴퓨터가 수행하는 단계이다. 

## 문제2
프로젝트 빌드 후 소스파일(c), 목적파일(obj), 실행파일(exe)의 위치를 찾아보라 -> 파일탐색기 검색화면을 첨부할 것
