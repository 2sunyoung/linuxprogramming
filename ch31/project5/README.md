# ch31 실습과제5

## 문제1
#ifndef ~ #endif 지시자를 사용하는 이유를 설명하라.

## 답
#ifndef ~ #endif 지시자는 매크로 상수가 정의되어 있지 않으면 해당 문장을 소스 코드에 포함하고, 이미 정의되어 있으면 제외하기 위해 사용한다. <br>
이때 매크로 상수의 값이 참인지 거짓인지는 관계없이 정의 여부만 확인한다. <br>
주로 헤더 파일이 중복으로 포함되는 것을 방지하기 위해 사용한다.

## 문제2
#ifndef ~ #endif 지시자를 사용한 예제를 인터넷에서 찾아서 실행해보고 소스코드를 자세히 설명하라.
