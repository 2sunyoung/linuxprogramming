# ch31 실습과제3

## 문제1
#if ~\#elif\~ #endif 지시자를 사용하는 이유를 설명하라.

## 답
if문은 실행단계에서 조건식에 따라 문장을 실행할지 말지를 결정하지만, #if~#endif 지시자는 선행처리단계에서 최종 소스코드에 넣을지 말지를 결정하기 때문에<br>
특정 조건에 맞는 코드만 컴파일할 수 있어 프로그램을 여러 환경이나 설정에 맞게 작성할 수 있다.<br>
#if는 조건을 검사하고, 조건이 거짓일 경우 #elif로 다른 조건을 검사한다. #endif는 조건부 컴파일의 끝을 나타낸다.

## 문제2
#if ~\#elif\~ #endif 지시자를 사용한 예제를 인터넷에서 찾아서 실행해보고 소스코드를 자세히 설명하라.
