# ch34 실습과제1

## 문제1
make, Makefile을 구분하여 차이점을 설명하라

## 답
make는 유닉스/리눅스 계열 운영체제에서 주로 사용되는 프로그램 빌드 자동화 도구이고,<br>
makefile은 프로그램을 컴파일하고 링크하는 방법을 알려주는 빌드 설정파일이다. (make를 실행하기 전에 먼저 작성해야 한다!!)<br>

## 문제2
프로그램 개발과정에서 GNU Make는 왜 필요한가?

## 답
GNU Make는 여러 소스 파일의 컴파일 과정을 자동화하고, 변경된 파일만 다시 컴파일하여 프로그램 개발의 효율성을 높이기 위해 사용한다.<br>

## 문제3
윈도우에서 사용한 Visual studio에서는 make의 역할을 누가하는가?

## 답
윈도우의 Visual Studio에서는 MSBuild가 GNU Make와 같은 역할을 한다.<br>
