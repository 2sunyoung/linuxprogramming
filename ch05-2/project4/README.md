# ch05-2 실습과제4

## 문제1
하드링크와 심볼릭 링크의 차이를 설명하라.

## 답
하드 링크는 실제 데이터 번지수를 직접 공유하는 또 다른 진짜 이름이라 원본을 지워도 내용이 남지만, 디렉터리나 다른 디스크에는 만들 수 없다.<br>
심볼릭 링크는 경로만 가리키는 바로가기 파일이라 원본을 지우면 끊어지지만, 디렉터리와 다른 디스크에도 제한 없이 생성할 수 있다.<br>

## 문제2
심볼릭 링크를 확인하는 명령어를 설명하라.

## 답
ls 명령어를 실행할 때 -l 옵션을 지정하면 심볼릭 링크 여부를 확인할 수 있다.<br>
어떤 파일에 연결되었는지 화살표(심볼릭링크->원본파일)로 표시된다.

## 답
디렉터리를 만들면 .(작업 디렉터리), ..(부모 디렉터리)가 기본적으로 생기기 때문에 하드링크 수가 2가 된다.<br>
