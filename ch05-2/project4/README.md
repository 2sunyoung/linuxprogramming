# ch05-2 실습과제4

## 문제1
하드링크와 심볼릭 링크의 차이를 설명하라.

## 답
하드링크는 원본 파일명 자체로, 파일 원본에 이름을 여러 개 붙이는 기능이다. <br>
하드링크로 여러 이름을 가지게 된 파일 중 하나를 삭제하면 지정한 이름의 파일명만 삭제될 뿐, 원본 파일들은 그대로 있다. (원본 파일은 모든 하드링크가 없져야 삭제)<br>
반면, 심볼릭 링크는 하드링크와 달리 디렉터리에도 만들 수 있고, 서로 다른 디스크에 걸쳐서 만들 수도 있다. 또 원본 파일에 대한 정보가 담긴 작은 특수 파일이 심볼릭 링크라서 원본과 구별된다. <br>
만약 이를 삭제한다면 심볼릭 링크 파일만 삭제되고 원본에는 어떠한 영향도 주지 않는다.

## 문제2
심볼릭 링크를 확인하는 명령어를 설명하라.

## 답
ls 명령어를 실행할 때 -l 옵션을 지정하면 심볼릭 링크 여부를 확인할 수 있다.<br>
어떤 파일에 연결되었는지 화살표(심볼릭링크->원본파일)로 표시된다.
