# ch32-1 실습과제2

## 문제1
1개의 정수를 키보드로부터 입력 받아 아래 함수값을 출력하는 프로그램을 작성하시오. <br>
단, 다음 조건을 만족시키도록 코드를 작성하시오.<br>
<img width="575" height="66" alt="image" src="https://github.com/user-attachments/assets/6b7d0b4e-2d19-4462-8bdd-bc9cdd975f58" /><br>

- 프로젝트의 구성 : main.c, mylib.h, mylib.c(파일이름은 변경가능)<br>
- main.c : 필요한 변수선언 및 함수호출 문장만으로 구성할 것<br>
- mylib.c ; 1개의 정수를 입력 받아 리턴하는 함수, 1개의 정수를 받아 위 함수값을 구하는 함수, 1개의 정수를 받아 화면에 출력하는 함수로 구성<br>
- mylib.h : mylib.c 에서 정의한 함수의 선언문 및 기타 선행처리문
