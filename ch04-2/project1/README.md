# ch04-2 실습과제1

## 문제1
ls 명령어의 4가지 옵션 -a, -l, -F, --help을 설명하고 각각 실행 예를 첨부하시오.

## 답
* -a - 숨겨진 파일도 함께 출력<br>
* -l - 파일명 뿐만 아니라 파일의 속성과 상세 정보까지 함께 출력<br>
* -F - 파일명 뒤에 파일의 종류를 의미하는 기호(보통 파일 - 기호없음 , 디렉터리 - / , 실행 가능 파일 - *, 심볼릭 링크 - @)를 추가해 출력 <br>
* --help - 여러 명령어 매뉴얼 출력 <br>
