| 기능 | 단축키 |
|---|---|
| 문자단위 커서이동 → 앞, 뒤, 맨앞, 맨뒤 | Ctrl + b (←), Ctrl + f (→), Ctrl + a (Home), Ctrl + e (End) |
| 단어단위 커서 이동 → 앞, 뒤 | Alt + b (단어단위 ←), Alt + f (단어단위 →) |
| 현재 위치 문자 삭제 | Ctrl + d (Delete) |
| 뒤에 있는 문자 삭제 | Ctrl + h (Backspace) |
| 뒤에 있는 단어 삭제 | Ctrl + w |
| 자르기 및 붙여넣기 | Ctrl + k (자르기), Ctrl + u (자르기), Ctrl + y (붙여넣기) |
| 화면 잠금 및 해제 | Ctrl + s (잠금), Ctrl + q (해제) |
| 실행종료 | Ctrl + c |
| 화면삭제 | Ctrl + l (명령어 clear도 동일한 기능 수행)|
