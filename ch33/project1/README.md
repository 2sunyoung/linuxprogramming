# ch32-2 실습과제1

## 문제1
정적라이브러리와 동적라이브러리의 차이를 설명하라 -> 정의, 링크시점, 장단점 등

## 답
정적 라이브러리는 링크 단계에서 링크되어 라이브러리 코드가 실행 파일 안에 복사되어 포함되는 방식(.a, .lib)이다. <br>
별도의 라이브러리 파일 없이도 실행할 수 있다는 장점이 있지만, <br>
프로그램마다 라이브러리 코드를 각각 가지므로 실행 파일 크기가 커지고 메모리도 많이 사용하며, 라이브러리를 수정하면 프로그램을 다시 빌드해야 한다. <br><br>
반면 동적 라이브러리는 실행 단계에서 링크되어 프로그램 실행 시점에 라이브러리를 불러와 사용하는 방식(.so, .dll)이다. <br>
여러 프로그램이 하나의 라이브러리를 메모리에서 공유할 수 있어 메모리 절약에 유리하고 실행 파일도 작으며, 라이브러리만 교체해도 갱신된다는 장점이 있다. <br>
다만 실행 환경에 해당 라이브러리가 반드시 있어야 하고 버전 호환 문제가 생길 수 있다.

## 문제2
gcc의 -I, -l, -L, -g, -v 옵션의 기능을 설명하라

## 답
-I<headerdir> : 헤더 파일 경로 지정<br>
-l<libname> : 정적 라이브러리 파일 지정<br>
-L<libpath>: 정적 라이브러리 파일 경로 지정<br>
-g : 디버그 모드로 컴파일, 기본 옵션은 릴리즈 모드<br>
-v : 실행되는 모든 명령어를 출력

## 문제3
빌드 모드인 디버그모드(-g 옵션)와 릴리즈 모드(-O1,2,3 옵션)의 차이를 설명하라

## 답
디버그 모드는 디버깅 정보를 포함하여 프로그램의 오류를 쉽게 찾고 수정하도록 한다. <br>
반면 릴리즈 모드는 -O1, -O2, -O3 등의 최적화 옵션을 사용하여 프로그램의 실행 효율을 높이는 데 목적이 있다. <br>
따라서 디버그 모드는 오류 수정에, 릴리스 모드는 실제 배포와 효율적인 실행에 적합하다.
