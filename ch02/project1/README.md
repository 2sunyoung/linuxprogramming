# ch02 실습과제1

## 문제1
리눅스 명령어가 무엇인지 설명하시오. 또, 실제 명령어의 정체는 무엇인가?

## 답
리눅스 명령어란 운영체제에게 작업을 지시하는 단어이고, 실제 명령어의 정체는 실행파일명이다.<br>

## 문제2
리눅스에서 가장 많이 사용되는 명령어 10개를 조사하고 설명하시오. 또 셸에서 실행하고 결과를 첨부하시오.

## 답
① pwd (Print Working Directory) - 현재 작동중인 디렉터리의 절대 경로를 출력한다. <br>
② ls (List Directory Contents) - 현재 위치한 디렉터리 내의 파일 및 폴더 목록을 출력한다. <br>
⠀⠀-l (상세 정보 표시), -a (숨김 파일 포함 표시)<br>
③ cd (Change Directory) - 작업 디렉터리를 변경하여 다른 폴더로 이동한다.<br>
⠀⠀cd Projects (Projects 폴더로 이동), cd .. (상위 폴더로 이동)<br>
④ mkdir (Make Directory) - 새로운 디렉터리를 생성한다.<br>
⑤ rm (Remove) - 파일이나 디렉터리를 삭제한다.<br>
⠀⠀-r (하위 디렉터리 포함 삭제), -f (강제 삭제)<br>
⑥ touch - 빈 파일을 생성하거나 파일의 수정 시간을 변경한다.<br>
⠀⠀-c (파일이 없어도 새로 생성하지 않음), -t (파일 시간을 특정 시각으로 변경)<br>
⑦ cp (Copy) - 파일이나 디렉터리를 복사한다.<br>
⠀⠀-r (하위 디렉터리 포함 복사), -i (덮어쓸 때 확인)<br>
⑧ mv (Move) - 파일이나 디렉터리를 이동하거나 이름을 변경한다.<br>
⠀⠀-f (강제 이동/덮어쓰기), -i (덮어쓸 때 확인)<br>
⑨ echo - 뒤에 입력한 문자열이나 변수의 값을 터미널 화면에 출력한다.<br>
⠀⠀-n (마지막 줄 바꿈을 하지 않음), -e (백슬래시 이스케이프 문자를 해석하여 출력)<br>
⑩ chmod (Change Mode) - 파일이나 디렉터리의 접근 권한을 변경한다.<br>
⠀⠀+x (실행 권한 부여), 755 (소유자 읽기·쓰기·실행 / 기타 읽기·실행)<br><br>

## 문제3
셸과 커널을 구분하여 자세히 설명하시오.

## 답
셸이란 사용자와 커널 사이에서 명령어를 받아들이고 커널의 실행 결과를 출력하는 소프트웨어로, 사용자의 요청을 받아서 커널에 전달하는 역할을 한다.<br>
커널이란 CPU나 메모리 같은 하드웨어를 관리하면서 명령어를 실행하고 프로세스를 관리하는 운영체제의 핵심 부분으로, 셸에 의해 보호된다.<br>

## 문제4
프롬프트 문자열에서 문자 ~의 의미를 조사하라.

## 답
프롬프트 문자열에서 '~'의 의미는 현재 위치한 작업 디렉터리가 '로그인한 사용자의 홈 디렉터리'임을 나타내는 약어이다.<br>
예시)<br>
'linux@DESKTOP-EH0BPJS:~$' → 현재 위치가 홈 디렉터리(/home/linux) 상태<br>
'linux@DESKTOP-EH0BPJS:/$' → 현재 위치가 시스템 최상위 디렉터리(/) 상태<br>
'linux@DESKTOP-EH0BPJS:~/dirA$' → 현재 위치가 홈 디렉터리 내부의 dirA 폴더 상태<br>
