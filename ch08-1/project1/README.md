# ch08-1 실습과제1

## 문제1
셸변수와 환경변수의 차이점을 설명하라.

## 답
셸 변수는 셸에서 사용하는 값이나 시스템 정보를 저장하는 변수이다. 셸 변수는 현재 실행 중인 셸에서 사용할 수 있으며, 셸이 종료되면 사라진다.<br>
환경 변수는 외부 명령어에서도 참조할 수 있도록 설정한 셸 변수이다. export 명령어를 사용하여 셸 변수를 환경 변수로 설정할 수 있다.<br>
즉, 셸 변수는 현재 셸에서 사용하고, 환경 변수는 외부 명령어에서도 사용할 수 있다.

## 문제2
환경변수 PS1, PATH, SHELL, LANG을 출력하고 기능을 설명하라.

## 답
<img width="1105" height="295" alt="image" src="https://github.com/user-attachments/assets/a36fe729-08f4-493d-ba45-922bbd7081d6" /><br>
- PS1 : 셸의 프롬프트 문자열을 정의하는 셸 변수이다.<br>
- PATH : 셸이 명령어의 위치를 찾는 디렉터리를 저장한다. 여러 디렉터리는 :로 구분한다.<br>
- SHELL : 현재 사용하는 셸의 정보를 저장하는 변수이다.<br>
- LANG : 언어, 지역, 문자 인코딩 등의 로케일 정보를 저장한다. 예를 들어 ko_KR.UTF-8은 한글 UTF-8 인코딩을 의미한다.

## 문제3
셸이 명령어 파일의 위치를 어떻게 찾는지 설명하라.

## 답
셸은 명령어를 실행할 때 PATH에 지정된 디렉터리를 찾아 명령어 파일의 위치를 확인한다.<br>
PATH에는 명령어를 찾을 디렉터리가 :로 구분되어 저장되어 있다. PATH에 지정된 디렉터리에서 명령어를 발견하면 실행하고, 찾지 못하면 오류가 발생한다.<br>
PATH에 명령어가 있는 경우에는 명령어 이름만 입력해서 실행할 수 있지만, PATH에 없는 경우에는 전체 경로를 입력해야 한다.<br>

## 문제7
환경변수에 경로를 추가할 때 $ PATH=‘$PATH:~/bin’ 처럼 작성하면 어떻게 되는지 설명하라.

## 답
작은따옴표 ' '를 사용하면 $PATH가 변수의 값으로 치환되지 않는다. $PATH의 기존 경로가 유지되는 것이 아니라 문자 그대로 $PATH:~/bin이 PATH에 저장된다.<br>
따라서 큰따옴표를 사용하는 것이 올바르다.
