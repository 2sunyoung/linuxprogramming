# ch01-2 실습과제1

## 문제1
가상머신이란 무엇인가?

## 답
가상화 소프트웨어를 이용하여 소프트웨어적으로 구현된 컴퓨터를 말한다.<br>

## 문제2
가상머신을 사용하는 이유를 설명하라.

## 답
가상머신은 하나의 컴퓨터에서 여러 운영체제를 동시에 실행할 수 있게 해준다.<br>
즉, 기존 컴퓨터의 운영체제를 건드리지 않고 다른 운영체제를 설치하고 사용할 수 있는 것이다.<br>
독립된 환경에서 개발 환경을 쉽게 만들고 삭제할 수 있어 개발 및 테스트 이용에 유용하다. <br>

## 문제3
WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?

## 답
① 완벽한 Linux 호환성 - 진짜 Linux 커널을 탑재하여 Docker, 대규모 컴파일 등 기존 WSL1에서 불가능했던 기능들이 완벽히 작동<br>
② 압도적인 속도 - Windows 파일 시스템과의 연동 속도가 비약적으로 상승하여 파일 읽기/쓰기 작업이 훨씬 빨라짐<br>
③ 낮은 자원 소모 - VirtualBox, Vmware 등과 달리 메모리와 CPU를 필요한 만큼만 동적으로 할당하여 PC 성능 저하가 거의 없음<br>
④ IDE 완벽 연동 - VS Code, IntelliJ 등 Windows에 설치된 개발 도구로 Linux 내부 코드를 직접 수정하고 디버깅 가능<br>

## 문제4
GUI, CLI의 장단점을 비교 설명하시오.

## 답
GUI는 그래픽을 통하여 사용자와 컴퓨터가 소통하는 방식으로, 주로 마우스를 사용하여 그래픽을 조작하기 때문에 매우 편리하고 직관적이다.<br>
하지만 통신 데이터량이 많아지면 속도가 느려진다는 단점이 있다.<br>
CLI는 명령어를 통하여 사용자와 컴퓨터가 소통하는 방식으로, 주로 키보드를 사용하여 데이터량이 적은 텍스트로만 입출력이 이루어지기 때문에 처리속도가 빠르다.<br>
하지만 GUI에 비해 덜 직관적이고, 관련 명령어도 알아야 사용이 가능하므로 초보 사용자는 이용에 어려움을 겪을 수도 있다.<br>

## 문제5
CLI방식의 인터페이스가 GUI방식보다 처리속도가 빠른 이유를 설명하라.

## 답
CLI는 통신 데이터량이 적은 텍스트만을 주고받기 때문에 처리속도가 빠르다.<br>

## 문제6
리눅스에서는 왜 CLI방식을 주로 사용하는가?

## 답
리눅스는 주로 서버 컴퓨터의 OS로 사용되며, 사용자가 네트워크를 통하여 원격 접속하여 작업을 처리하기 때문에 CLI를 주로 사용한다. <br>
GUI 방식은 통신 데이터량이 많아 속도가 느려질 수 있으므로, 통신 데이터량이 작은 텍스트를 주고받는 CLI를 사용하여 처리속도를 빠르게 한다.<br>

## 문제7
리눅스 명령어란 무엇이고 중요 5개 명령어를 조사하라. 실행결과를 첨부하라

## 답
리눅스 명령어란 CLI 환경에서 사용자가 운영체제에 특정 작업을 수행하도록 지시하는 단어이다. <br>
중요 명령어는 다음과 같다. <br>
① pwd (Print Working Directory) - 현재 작동중인 디렉터리의 절대 경로를 출력한다. 
  -l (상세 정보 표시), -a (숨김 파일 포함 표시)<br>
② ls (List Directory Contents) - 현재 위치한 디렉터리 내의 파일 및 폴더 목록을 출력한다. 
  cd Projects (Projects 폴더로 이동), cd .. (상위 폴더로 이동)<br>
③ cd (Change Directory) - 작업 디렉터리를 변경하여 다른 폴더로 이동한다.<br>
④ mkdir (Make Directory) - 새로운 디렉터리를 생성한다.<br>
⑤ rm (Remove) - 파일이나 디렉터리를 삭제한다.
