# ch01-1 실습과제1

## 문제1
UNIX 운영체제에 대하여 조사하시오.

## 답
UNIX란 1969년 미국의 AT&T 벨 연구소에서 켄 톰프슨, 데니스 리치 등이 개발한 운영체제이다.<br>
UNIX의 주요 특징은 다음과 같다.<br>
① 다중 사용자 시스템 - 여러 사용자가 하나의 컴퓨터에 동시에 접속하여 작업할 수 있다.<br>
② 다중 작업 지원 - 여러 프로그램을 동시에 실행하고 처리할 수 있다.<br>
③ 계층적 파일 시스템 - 파일과 디렉터리를 최상위 디렉터리 /를 기준으로 트리 구조로 관리한다.<br>
④ 높은 이식성 - C언어로 개발되어 다양한 컴퓨터 시스템에 쉽게 적용할 수 있다.<br>
⑤ 강력한 명령어 환경 - 명령어를 조합하여 파일, 프로세스, 네트워크 등을 효율적으로 관리할 수 있다.<br>
⑥ 파일 중심의 설계 - 장치와 입출력 요소까지 파일과 유사하게 다루어 시스템 자원을 일관되게 관리한다.<br>

## 문제2
Linux, Windows, macOS 를 비교 설명하시오.

## 답
Linux는 유닉스와 호환되는 open source 운영체제이다. 모바일, 임베디드, 서버컴퓨터에서 주로 사용된다.<br>
Windows는 Microsoft에서 개발한 GUI 기반 운영체제이다. 가장 널리 사용되고 있으며, 개인용 컴퓨터에서 주로 사용된다.<br>
macOS는 애플에서 개발한 유닉스 계열의 애플 컴퓨터 전용 운영체제이다. <br>

## 문제3
우분투(Ubuntu) 리눅스에 대하여 조사하시오.

## 답
Ubuntu는 Linux 커널(= 운영체제의 핵심 부분)을 기반으로 한 대표적인 오픈 소스 운영체제이다.<br>
사용하기 쉬운 GUI 환경을 제공하면서도 터미널을 통한 명령어 작업도 가능하다.<br>
개인용 컴퓨터뿐만 아니라 서버, 클라우드, 개발 및 임베디드 환경에서도 널리 사용된다.<br>
대표적인 특징으로는 무료, 높은 보안성, 다양한 소프트웨어 지원, 커스터마이징이 자유롭다는 점이 있다.<br>

## 문제4
임베디드 시스템용 운영체제로 리눅스가 적합한 이유를 설명하라.

## 답
다양한 하드웨어를 지원하여 여러 임베디드 장치에 적용하기 쉽다.<br>
가볍게 구성할 수 있어 제한된 CPU와 메모리를 가진 장치에서도 사용할 수 있다.<br>
네트워크 기능과 다양한 드라이버를 지원하여 임베디드 환경에 활용하기 좋다.<br>
