# ch01-1 실습과제1

## 문제1
UNIX 운영체제에 대하여 조사하시오.

## 답
UNIX는 벨 연구소에서 개발된 c언어로 작성된 최초의 운영체제로, 윈도우즈를 제외한 모든 운영체제의 조상이라고 할 수 있다.<br>

## 문제2
Linux, Windows, macOS 를 비교 설명하시오.

## 답
Linux는 리누스 토발스가 개발한 유닉스와 호환 오픈 소스 운영체제이다. 모바일, 임베디드, 서버컴퓨터에서 주로 사용된다.<br>
Windows는 Microsoft에서 개발한 GUI 기반 운영체제이다. 가장 대중적이고, 개인용 PC 점유율 1위다.<br>
macOS는 애플에서 개발한 유닉스 계열의 애플 컴퓨터 전용 운영체제이다. <br>

## 문제3
우분투(Ubuntu) 리눅스에 대하여 조사하시오.

## 답
우분투는 초보자도 사용하기 쉬운 GUI 환경과 APT를 제공하는 대표적인 오픈소스 리눅스 배포판이다.<br>

## 문제4
임베디드 시스템용 운영체제로 리눅스가 적합한 이유를 설명하라.

## 답
리눅스는 무료이고, 가벼운데 훌륭한 성능에 다양한 하드웨어 아키텍처를 지원하기 때문이다.<br>
